## 角色设计 Gate：三个成长阶段 × 正反两面
角色进入移动与互动开发前，必须先完成六面静态验收；任何一面未确认，不得锁版角色。

### 幼年期 Baby
- [ ] 正面：比例、脸型、耳朵、花纹、四肢与尾巴一致
- [ ] 正面：头部蝴蝶结、围兜、铃铛完整
- [ ] 背面：头型、耳朵、背部花纹与正面设定连续
- [ ] 背面：只显示后颈围兜绑带／蝴蝶结，不出现正面围兜主体
- [ ] 背面：尾巴从身体后方正确长出
- [ ] 正反两面都有圆形小手，脚底位置一致

### 青少年期 Teen
- [ ] 正面：比例与幼年期有明确成长差异，但仍为同一角色
- [ ] 正面：斜背小包／服装位置与比例正确
- [ ] 背面：头型、耳朵、背部花纹与正面设定连续
- [ ] 背面：斜背带与包体符合真实前后关系，不复制正面图层
- [ ] 背面：尾巴层级正确
- [ ] 正反两面手脚与脚底锚点一致

### 成年期 Adult
- [ ] 正面：体型与前两阶段形成明确成长关系
- [ ] 正面：深蓝／靛蓝背心及金色小细节正确
- [ ] 背面：头型、耳朵、背部花纹与正面设定连续
- [ ] 背面：背心必须有真实背面结构，不复制正面装饰
- [ ] 背面：尾巴层级正确
- [ ] 正反两面手脚与脚底锚点一致

### 六面一致性检查
- [ ] Baby front ↔ back 是同一只猫
- [ ] Teen front ↔ back 是同一只猫
- [ ] Adult front ↔ back 是同一只猫
- [ ] Baby → Teen → Adult 能看出同一角色自然成长
- [ ] 三阶段基础毛色、核心花纹与辨识特征连续
- [ ] 三阶段服装／配件各自独立，不因切换方向消失或穿帮
- [ ] 左右方向仅在适合镜像时使用；非对称配件不得因镜像改变设定
