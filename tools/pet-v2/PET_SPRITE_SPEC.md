# Pet Sprite Design Spec v1.0

本文件定義謎屿寵物小屋 V2 後續所有寵物角色的靜態 Sprite 設計與驗收規範。新增任何物種前，先依本規範完成角色，再進入動作、碰撞與互動層。

## 1. 六面靜態驗收先於動作

每隻寵物都必須先完成：

- Baby：正面、背面
- Teen：正面、背面
- Adult：正面、背面

共 6 個靜態面。六面全部通過後，才能開始走路、轉身、互動等動作。

## 2. 正背面必須是同一隻角色

- 頭型、耳型、毛色、頭紋、身體比例要一致。
- 背面不可只把正面鏡像，也不可重新畫成另一隻角色。
- 三個成長階段要看得出是同一隻寵物逐步長大。
- Teen 比 Baby 稍成熟；Adult 比 Teen 更穩重，但不可改變核心辨識特徵。

## 3. 手腳共用規則

- 同一階段的正面／背面，手掌、拳頭尺寸與形狀一致。
- 正面與背面不可各自使用不同手型。
- Baby／Teen／Adult 可因身形不同而等比例調整，但同階段正背必須一致。

## 4. 主描邊統一

- 頭、身體、手、腳、尾巴使用一致的深棕主描邊。
- 手掌／拳頭不得只是淺色填色塊。
- 像素角色優先使用「深色完整外形底層 + 淺色內填」的做法，不依賴 CSS stroke 硬補輪廓。
- 拳頭描邊粗細必須與頭、身體、腳的主描邊一致。
- 所有外框需連續閉合，不可有破邊、缺角或局部特別細。

## 5. 服裝必須是完整實心結構

- Teen 上衣、Adult 背心正面與背面都必須有完整衣身。
- 禁止只畫衣服外框造成腹部／背部鏤空。
- 正確順序：完整底色 → 領口／下擺 → 陰影 → 裝飾細節。

## 6. 服裝正背要符合穿戴邏輯

- 斜背包正面：背帶需由一側肩膀斜向對側包包。
- 背面：背帶方向必須與正面連續，包包要合理轉位。
- Adult 背心背面必須有真正背面結構，不可直接複製正面。

## 7. 尾巴規範

### 正面

- 尾巴位置依物種特徵設計，但不可干擾主體輪廓辨識。

### 背面

- 根部從臀部中央偏下開始，而不是腰側。
- 根部先向上，再自然往側邊彎。
- 目前 V2 視覺規則：背面尾巴放在最前圖層。
- 根部到末端粗細應接近一致，末端不可突然膨大。
- 尾巴內色必須由根部開始完整填滿，不可有空洞或漏色。
- 外框必須連續閉合，不能因收細而出現破碎描邊。

## 8. 配件正背規則

- 正面配件與背面結構要分開設計，不可直接複製。
- Baby 頭部蝴蝶結只在正面可見。
- Baby 圍兜正面有完整圍兜／鈴鐺；背面只保留後頸綁帶／蝴蝶結。
- 任何包包、背帶、帽子、領結等，都要檢查轉身後的合理位置。

## 9. SVG 幾何優先，不靠後製補救

每個部件都應直接在 SVG 幾何中畫正確，不用 CSS 勉強修形。

建議固定 group：

- `head`
- `body`
- `arms`
- `legs`
- `tail`
- `clothes`
- `accessory`

角色之後要做走路、揮手、互動時，必須可以獨立控制各部件，不應因修改一個部件而破壞其他結構。

## 10. 建議圖層順序

一般角色：

1. shadow
2. legs
3. body
4. clothes
5. arms
6. head
7. accessories
8. 特殊前景部件

若背面尾巴採本版 V2 規則，尾巴放在「特殊前景部件」層。

## 11. 新物種建立方式

不要從零各畫一套。先沿用共用角色骨架，再替換：

- 耳朵
- 臉型
- 毛色／花紋
- 尾巴
- 物種專屬特徵

手、腳、描邊規則、服裝結構、圖層、正背驗收邏輯盡量共用。

## 12. 六面交付前自檢清單

每次新增寵物，提交驗收前必須自行確認：

- [ ] Baby 正面／背面完成
- [ ] Teen 正面／背面完成
- [ ] Adult 正面／背面完成
- [ ] 六面看起來都是同一隻角色
- [ ] 正背手型一致
- [ ] 拳頭完整描邊，粗細與全身一致
- [ ] 上衣／背心無鏤空
- [ ] 背帶正背方向連續
- [ ] 尾巴根部在正確位置
- [ ] 尾巴先上揚再側彎
- [ ] 尾巴粗細一致
- [ ] 尾巴內色填滿
- [ ] 尾巴外框連續無破邊
- [ ] 正背配件符合真實穿戴邏輯
- [ ] 無 CSS 臨時修補造成的破邊或比例異常

只有以上全部通過，角色才能標記為 `sprite-static-stable`，並進入動作層。
