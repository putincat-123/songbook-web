🎧 Miyu 批量回放工具
这个工具必须在已登录猫耳主播账号的 missevan.com 页面里运行，才会自动沿用现有登录状态读取直播回放。不会保存账号密码。
推荐：做成浏览器书签 拖我到书签栏：Miyu 批量回放
使用方法
  1. 先在电脑浏览器登录猫耳主播账号。
  2. 打开主播主页的“声音”页面。
  3. 点击书签栏里的 Miyu 批量回放。
  4. 工具会读取全部声音分页，自动分成“直播回放 / 主頁音频 / 疑似处理中”。
  5. 直播回放可勾选后逐个取得当前有效的 128k 音频地址并下载。
第一版默认主播 user_id 为 24313174（谜屿）。工具只读取猫耳页面本身可访问的数据；回放地址带时效签名，下载时会重新取得。
