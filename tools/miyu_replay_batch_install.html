🎧 Miyu 批量回放

Chrome 會基於安全機制，把「貼上」的 javascript: 前綴移除。這次改成：前綴自己打、後半段再貼，就不會被當成 Google 搜尋。
② 安裝方式
  1. 先把這個頁面加入書籤（⌘D）。
  2. 在書籤列找到它，右鍵 →「編輯」。
  3. 名稱改成「🎧 Miyu 批量回放」。
  4. 把「網址」欄全部刪掉。
  5. 用鍵盤親手輸入 javascript:
  6. 緊接著按 ⌘V，貼上剛才複製的後半段程式碼，中間不要空格。
  7. 儲存。
最後網址開頭一定要看得到 javascript:。如果開頭是 (()=>，點下去就會變成 Google 搜尋。
③ 使用
  1. 登入猫耳主播帳號。
  2. 打開主播「聲音」頁。
  3. 點書籤列的「🎧 Miyu 批量回放」。
工具在猫耳頁面內執行，直接沿用目前登入狀態，不保存帳號密碼。
